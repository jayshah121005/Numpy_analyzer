# NumPy Analyzer

## About the Project

NumPy Analyzer is a simple Python project made using **NumPy**.
The project is used to work with numerical data and perform different operations such as searching, sorting, filtering, and analyzing data.

The main purpose of this project is to practice NumPy concepts and understand how numerical data can be handled using Python.

## Features

* Create and work with NumPy arrays
* Display data
* Search for values
* Sort data
* Filter data using conditions
* Find maximum and minimum values
* Calculate basic statistics
* Perform array operations
* Easy menu-based program

## Technologies Used

* Python
* NumPy

## Installation

First, make sure Python is installed on your computer.

Install NumPy using:

```bash
pip install numpy
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/jayshah121005/Numpy_analyzer.git
```

Go inside the project folder:

```bash
cd Numpy_analyzer
```

Run the Python file:

```bash
python Numpy_analyzer.py
```

## Example Operations

The program allows the user to perform operations like:

```text
1. Display Data
2. Search Data
3. Sort Data
4. Filter Data
5. Find Maximum
6. Find Minimum
7. Statistics
8. Exit
```

The user can select an option from the menu and perform the required operation.
